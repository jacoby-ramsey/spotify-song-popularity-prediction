# Dataset

This project uses the Spotify Tracks DB dataset containing information

on more than 230,000 Spotify tracks, including audio characteristics,

genre classifications, and popularity scores.

## Source

The original dataset is available on Kaggle:

[Download the Spotify Dataset](https://www.kaggle.com/datasets/zaheenhamidani/ultimate-spotify-tracks-db)

## Data Availability

The full dataset is not stored in this repository due to GitHub's file

size limitations. Download the dataset from the link above to reproduce

the analysis.
